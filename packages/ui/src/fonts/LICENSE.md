# Font licences

Both faces are **SIL Open Font License 1.1**, which permits embedding, self hosting and
commercial use.

| Face | Weights | Licence | Source |
|---|---|---|---|
| Titillium Web | 400, 600 | SIL OFL 1.1 | Accademia di Belle Arti di Urbino, via Google Fonts |
| Cormorant Garamond | 400, 500 | SIL OFL 1.1 | Christian Thalmann, via Google Fonts |

## Formula1 Display is deliberately absent

The brand guideline names "F1 Display", and the supplied font pack contains Formula1 Display
Regular, Bold and Wide, downloaded from blogfonts.com.

**It is not deployed.** That is not a licensed distribution of what is Formula One's proprietary
corporate typeface, and serving it from a commercial client site is a real trademark exposure,
with Brightex as the party serving it. See D3 and `docs/DECISIONS.md`.

Formula1 remains only where it is already outlined as vector inside the logo artwork, which is
not a webfont and not a redistribution.

**If Beco produces evidence of a commercial licence**, adding it is a change to this directory
and one line in `tokens.css`, not a redesign.
